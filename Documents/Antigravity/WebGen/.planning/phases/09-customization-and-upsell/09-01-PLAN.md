  <action>
Create POST endpoint at `/api/uploads` that receives multipart FormData with fields: `file` (File), `claimId` (string), `type` ("logo" | "photo").

Validation chain (in order):
1. Check all three fields present, return 400 if missing
2. Check `file.size <= 5 * 1024 * 1024` (5MB), return 400 with "File exceeds 5MB limit"
3. Read file as ArrayBuffer, extract first 4 bytes as Uint8Array
4. Validate magic bytes: PNG = `[0x89, 0x50, 0x4E, 0x47]`, JPEG = `[0xFF, 0xD8, 0xFF]`, WebP = `[0x52, 0x49, 0x46, 0x46]`. Return 400 with "Invalid file type. Only PNG, JPG, and WebP allowed." if none match
5. Verify claim is paid: query `claims` table with `claimId`, check status is `paid` or `customizing`. Return 403 with "Unauthorized" if not

On validation pass:
- Generate safe filename: `${Date.now()}-${Math.random().toString(36).slice(2, 8)}.${ext}` where ext comes from original filename (fallback to 'png')
- Build path: `${claimId}/${type}/${safeName}`
- Upload to `claim-uploads` bucket using `createAdminClient().storage.from('claim-uploads').upload(path, buffer, { contentType: file.type, cacheControl: '3600' })`
- Return JSON `{ path, bucket: 'claim-uploads' }` with 200
- On upload error return 500 with "Upload failed"

Wrap entire handler in try/catch. Log errors with `[Uploads]` prefix.

IMPORTANT: Do NOT use signed URLs for upload -- upload directly server-side to bypass CORS entirely (research P11). Do NOT accept SVG (security risk per research P6). Do NOT store the full URL in the response -- return only the storage path (research P7).
