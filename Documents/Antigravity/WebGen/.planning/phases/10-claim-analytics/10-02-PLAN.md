```typescript
interface FunnelStep {
  step: string           // Human-readable label
  eventType: string      // Maps to ClaimEventType
  count: number
  dropOff: number        // Percentage drop from previous step (0 for first)
}

export async function getFunnelData(days: number = 7): Promise<FunnelStep[]> {
```

Implementation:
- Define the funnel step order as a constant array:
  ```typescript
  const FUNNEL_STEPS = [
    { step: 'Claim Page Views', eventType: 'claim_page_view' },
    { step: 'Plan Selected', eventType: 'plan_selected' },
    { step: 'Payment Initiated', eventType: 'payment_initiated' },
    { step: 'Payment Completed', eventType: 'payment_completed' },
    { step: 'Customization Submitted', eventType: 'customization_submitted' },
  ] as const
  ```
- Query `claim_events` for the date range, selecting `event_type` column only.
- Use JS-side aggregation (matching the v1.0 analytics pattern — Supabase JS client has no GROUP BY): count occurrences of each event_type using a `Record<string, number>` map.
- Map FUNNEL_STEPS to FunnelStep[], computing `dropOff` as: `previousCount > 0 ? Math.round(((previousCount - currentCount) / previousCount) * 100) : 0`. First step has dropOff = 0.
- Wrap in try/catch, return empty array on error (matching existing pattern).

**2. `getRevenueStats(days: number)` server action:**
Returns revenue aggregation from the `claims` table (NOT claim_events — revenue comes from actual paid claims).

```typescript
interface RevenueStats {
  totalRevenue: { inr: number; usd: number }  // In rupees/dollars (not paise/cents)
  byPlan: Array<{ plan: string; count: number; revenue: number; currency: string }>
  conversionRate: number  // claim_page_view -> payment_completed percentage
}

export async function getRevenueStats(days: number = 7): Promise<RevenueStats> {
```

Implementation:
- Query `claims` table where `status` is in `['paid', 'customizing', 'completed']` and `paid_at` is within the date range.
- Aggregate in JS: sum `amount_paise` grouped by `plan` and `currency`. Convert paise to rupees (divide by 100) and cents to dollars (divide by 100) for display.
- For conversionRate: query claim_events for `claim_page_view` count and `payment_completed` count in the same date range. Rate = `(completed / views) * 100` rounded to 1 decimal. Return 0 if no views.
- Wrap in try/catch, return empty stats on error.

```typescript
import { Suspense } from 'react'
import { getFunnelData, getRevenueStats } from './actions'
import { FunnelChart } from '@/components/analytics/funnel-chart'
import { FunnelDateFilter } from '@/components/analytics/funnel-date-filter'
import { RevenueSummary } from '@/components/analytics/revenue-summary'

interface FunnelPageProps {
  searchParams: Promise<{ days?: string }>
}

export default async function FunnelPage({ searchParams }: FunnelPageProps) {
  const params = await searchParams
  const days = Math.max(1, Math.min(30, parseInt(params.days || '7', 10) || 7))

  const [funnelData, revenueStats] = await Promise.all([
    getFunnelData(days),
    getRevenueStats(days),
  ])

  return (
    <div className="space-y-6">
      <div>
        <h2 className="text-2xl font-bold tracking-tight">Claim Funnel</h2>
        <p className="text-muted-foreground text-sm mt-1">
          Conversion funnel and revenue from claim flow
        </p>
      </div>

      <Suspense fallback={null}>
        <FunnelDateFilter />
      </Suspense>

      <div className="space-y-6">
        <FunnelChart data={funnelData} />
        <RevenueSummary data={revenueStats} />
      </div>
    </div>
  )
}
```
