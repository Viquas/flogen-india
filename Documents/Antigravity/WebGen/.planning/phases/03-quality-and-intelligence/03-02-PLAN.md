  <files>webgen/lib/ai/template-seeder.ts</files>
  <action>
Create `webgen/lib/ai/template-seeder.ts` with two exported functions:

**1. `sanitizeTemplateCode(code: string, businessData?: Record<string, unknown>): string`**

Replaces business-specific content with placeholders to prevent data bleed:

a) If `businessData` is provided, extract and replace:
   - `businessData.businessName` or `businessData.brandIdentity?.core?.brandName` -> `{{business_name}}`
   - Phone numbers matching `/\b\d{3}[-.]?\d{3}[-.]?\d{4}\b/g` -> `{{phone}}`
   - Email addresses matching `/\b[\w.-]+@[\w.-]+\.\w+\b/g` -> `{{email}}`
   - Street addresses (simplistic: lines with numbers followed by street/ave/blvd/rd/dr/ln/ct/way) -> `{{address}}`

b) Always replace (regardless of businessData):
   - Phone numbers, emails (same patterns as above, catches any remaining)
   - Replace business name occurrences case-insensitively using `new RegExp(escapeRegex(name), 'gi')`

c) Helper: `escapeRegex(str: string): string` -- escapes special regex characters in a string.

d) Truncate to structural excerpt: If sanitized code exceeds 150 lines, keep only the first 120 lines and add a comment `// ... (truncated for brevity)`. This limits token cost and focuses the LLM on structure, not content.

**2. `getFewShotContext(industry: string, maxExamples: number = 1): Promise<string | null>`**

Queries the templates table for matching industry examples:

a) Import `createAdminClient` from `@/lib/supabase/admin`
b) Query: `supabase.from('templates').select('code, industry_tag, name').eq('industry_tag', industry).order('rating', { ascending: false }).limit(maxExamples)`
c) If no results, try a broader match: `supabase.from('templates').select('code, industry_tag, name').order('rating', { ascending: false }).limit(1)` -- use the best template regardless of industry as fallback. If still no results, return `null`.
d) For each template result, call `sanitizeTemplateCode(template.code)` to sanitize.
e) Format as a few-shot prompt block:

```
Here is a high-quality example of a ${industry} website for structural reference. Use it as inspiration for layout and section organization, but generate ORIGINAL content for the new business:

--- EXAMPLE: ${template.name} ---
${sanitizedCode}
--- END EXAMPLE ---
```

f) Wrap the entire function in try/catch. If any error occurs (DB failure, etc.), log it and return `null`. Never throw -- generation must proceed without few-shot context if template lookup fails.
