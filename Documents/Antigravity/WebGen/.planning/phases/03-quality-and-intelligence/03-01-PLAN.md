**2. Create webgen/lib/ai/quality-scorer.ts:**

Export a `QualityScore` interface and `scoreGeneratedCode` pure function:

```typescript
export interface QualityScore {
  overall: number          // 0-100 composite
  renderSuccess: boolean   // from validation result
  sectionCount: number     // detected sections out of 9
  sectionCompleteness: number  // 0-30 points
  codeStructure: number    // 0-15 points
  dataUsage: number        // 0-15 points
  details: Record<string, boolean>  // per-section presence map
}
```

The `scoreGeneratedCode(code: string, businessData: Record<string, unknown>, validationPassed: boolean): QualityScore` function must:

a) **Render success (40 points):** If `validationPassed` is true, award 40 points. Otherwise 0.

b) **Section completeness (30 points):** Detect 9 expected sections using regex patterns on the code string:
   - navigation: `/nav\b/i`, `/navbar/i`, `/header.*nav/i`, `/mobile.*menu/i`
   - hero: `/hero/i`, `/jumbotron/i`, `/banner/i`
   - features: `/features?/i`, `/services?/i`, `/offerings?/i`
   - about: `/about/i`, `/who.*we.*are/i`, `/our.*story/i`
   - testimonials: `/testimonial/i`, `/review/i`, `/what.*clients.*say/i`
   - faq: `/faq/i`, `/frequently.*asked/i`, `/questions?/i`
   - cta: `/cta/i`, `/call.*to.*action/i`, `/get.*started/i`, `/book.*now/i`
   - contact: `/contact/i`, `/get.*in.*touch/i`, `/reach.*out/i`
   - footer: `/footer/i`, `/copyright/i`

   Score: `Math.round((detectedCount / 9) * 30)`

c) **Code structure (15 points):** Award points for structural quality signals:
   - Has `export default function` (5 pts)
   - Has `useState` or `useEffect` (3 pts -- indicates interactivity)
   - Has responsive classes like `md:` or `lg:` or `sm:` (4 pts)
   - Has `className` usage (3 pts -- Tailwind styling)

   Cap at 15.

d) **Data usage (15 points):** Check if business-specific data appears in the code:
   - Business name from `businessData.businessName` or `businessData.brandIdentity?.core?.brandName` found in code (5 pts)
   - No lorem ipsum text: code does NOT match `/lorem\s+ipsum/i` (5 pts)
   - Phone/email/address from businessData.contactInfo appears (5 pts)

   Cap at 15.

e) **Overall:** Sum all sub-scores. Clamp to 0-100 range.

The function must be synchronous, pure (no DB, no side effects), and never throw. Wrap all regex operations in try/catch to handle catastrophic backtracking on malformed code. If any sub-score computation throws, default that sub-score to 0 and continue.

**1. Hook scorer into generator.ts generateAndSaveWebsite():**

After `updateProjectWithCode` succeeds (after line 491 `await supabase.from('projects').update({ generation_phase: null }).eq('id', projectId)`) and before the `return { success: true, code: validatedCode }` (line 497), add a fire-and-forget scoring block:

```typescript
// --- 4. QUALITY SCORING (fire-and-forget, never blocks generation) ---
try {
  const { scoreGeneratedCode } = await import('./quality-scorer')
  const score = scoreGeneratedCode(validatedCode, data as Record<string, unknown>, !fixFailed)
  await supabase
    .from('projects')
    .update({ quality_score: score.overall })
    .eq('id', projectId)
} catch (scoreErr) {
  console.error(`[QualityScorer] Scoring failed for ${projectId}:`, scoreErr)
  // Never block generation for scoring failure
}
```

Note: At this point in the function, `fixFailed` is guaranteed false (the early return at line 478-486 handles the fixFailed=true case). So `!fixFailed` will always be `true` here. This is correct -- we only score projects that passed validation.
