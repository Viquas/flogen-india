  <action>
Create `webgen/lib/cta-injector.ts` implementing the CTA bar injection.

The module exports:
1. `CtaConfig` interface: `{ businessName: string, claimUrl: string, expiresAt: string }`
2. `injectCtaBar(html: string, config: CtaConfig): string` -- takes HTML output from `constructHtmlBoilerplate()` and injects the CTA bar before `</body>`.

Implementation requirements (from research):

**Style isolation (CTA-03):**
- ALL styles must be inline (no Tailwind classes, no external CSS)
- ALL element IDs prefixed with `flogen-cta-` to avoid collisions
- `z-index: 2147483647` (max 32-bit signed integer)
- The CTA root is a direct child of `<body>`, not inside `<div id="root">`, so it sits outside the React app's stacking context
- Add `document.body.style.paddingBottom = "64px"` via script so page content is not hidden behind the bar

**CTA bar content (CTA-01):**
- Dark semi-transparent bar (`rgba(17, 17, 17, 0.95)`) with blur backdrop
- Left side: "Made for {Business Name}" (truncated with ellipsis if too long)
- Right side: Blue "Claim This Website" button linking to `claimUrl`
- System font stack: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`

**Countdown timer (CTA-02):**
- Below the business name, shows "{N}d {N}h {N}m left to claim"
- Uses vanilla JavaScript with UTC timestamp math
- Reads the absolute `expiresAt` ISO timestamp (not relative offset)
- Re-syncs every 60 seconds (not 1 second -- minute-level precision is sufficient)
- Each tick re-computes from `Date.now()` to prevent drift

**Expired state (CTA-04):**
- When `expiresAt < Date.now()`, countdown text changes to "This offer has expired" in red (#f87171)
- Button text changes to "Request a New Website"
- Button background changes to gray (#6b7280)
- Button href appends `?expired=true` to the claim URL
- Timer stops (clearInterval) after detecting expiry

**HTML safety:**
- Escape businessName for HTML embedding: replace &, <, >, " with entities
- The claimUrl and expiresAt are also escaped

Use the `buildCtaBarHtml()` helper function from the research doc as the reference implementation. The complete CTA is a single HTML string containing a `<div>` and a `<script>` block.

**Anti-patterns to avoid:**
- Do NOT use Tailwind classes (generated page's Tailwind config can override)
- Do NOT inject into the React source code (it's JSX, CTA is HTML)
- Do NOT modify `constructHtmlBoilerplate()` directly
- Do NOT use Shadow DOM or iframe wrapper for the CTA
- Do NOT use relative time offsets for countdown

```typescript
import chromium from '@sparticuz/chromium-min'
import puppeteer from 'puppeteer-core'
import { createAdminClient } from '@/lib/supabase/admin'
import { constructHtmlBoilerplate } from '@/lib/utils/html-boilerplate'

const CHROMIUM_URL = process.env.CHROMIUM_REMOTE_URL
    || 'https://github.com/nicehash/chromium-bin/releases/download/v133.0.0/chromium-v133.0-pack.tar'

export async function generateScreenshot(
    projectId: string,
    generatedCode: string
): Promise<string | null> {
    let browser
    try {
        browser = await puppeteer.launch({
            args: chromium.args,
            executablePath: await chromium.executablePath(CHROMIUM_URL),
            headless: chromium.headless,
        })
        const page = await browser.newPage()
        await page.setViewport({ width: 1280, height: 800 })

        const html = constructHtmlBoilerplate(generatedCode)
        await page.setContent(html, { waitUntil: 'networkidle0', timeout: 15000 })
        const buffer = await page.screenshot({ type: 'webp', quality: 80 })

        const supabase = createAdminClient()
        const path = `${projectId}/preview.webp`
        const { error: uploadError } = await supabase.storage
            .from('site-screenshots')
            .upload(path, buffer, {
                contentType: 'image/webp',
                upsert: true,
            })

        if (uploadError) {
            console.error('[Screenshot] Upload failed for', projectId, uploadError)
            return null
        }

        const { data } = supabase.storage.from('site-screenshots').getPublicUrl(path)

        // Update project record with screenshot URL
        await supabase.from('projects')
            .update({ screenshot_url: data.publicUrl })
            .eq('id', projectId)

        return data.publicUrl
    } catch (err) {
        console.error('[Screenshot] Failed for', projectId, err)
        return null
    } finally {
        if (browser) await browser.close()
    }
}
```

The function:
1. Launches headless Chromium via puppeteer-core + @sparticuz/chromium-min
2. Sets viewport to 1280x800
3. Renders the generated code using constructHtmlBoilerplate (same as preview)
4. Captures a WebP screenshot at 80% quality
5. Uploads to the `site-screenshots` Supabase Storage bucket
6. Updates the project's `screenshot_url` column
7. Returns the public URL or null on failure
8. Always closes the browser in the finally block

This function is meant to be called from batch processing pipelines (e.g., after quality scoring in autopilot). It is NOT called on page load. Screenshot generation takes 5-15 seconds on Vercel serverless.

NOTE: The `page.screenshot()` returns a `Buffer` (or `Uint8Array`) which Supabase Storage accepts directly.
