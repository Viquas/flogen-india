# v2.0 — Agentic Claude Generation via Subscription CLI

> Executed by subagent-driven-development. Single-call v2.0 (critique loop is a later v2.1).

**Goal:** For high-value leads, the local worker generates the site by shelling out to the user's logged-in `claude` CLI (their subscription) — one strong Claude Sonnet call producing the full award-grade React site — instead of the Gemini `generateAndSaveWebsite`. Templates stay for the cron's volume path.

**Decision (user):** Auth = subscription CLI (`claude -p`, no API key). Depth = single strong call.

**Compliance note (documented in README):** the Claude subscription is licensed for interactive/personal use. This path is fine for the user's own low-volume high-value leads; a commercial production backend at volume should switch to the Anthropic API. The module is written so swapping the provider later is a localized change.

## Task 1: claude-cli module
`lib/generation/claude-cli.ts`:
- `buildClaudePrompt(businessData, knowledge): string` (pure) — assembles ONE self-contained prompt: (a) the code-generator architecture + contrast rules (`CODE_GENERATOR_PROMPT` from `@/lib/ai/prompts/code-generator`), (b) craft-core (read `design-knowledge/craft/core.md`), (c) the niche design-knowledge (`selectKnowledge(industry, projectId)` from `@/lib/ai/design-knowledge` — use its `dlsBlock`+`exemplarBlock`), (d) the real business data block (businessName, category/industry, formattedAddress/suburb, phone, rating, userRatingCount, real review snippets, real Places photo URLs via the existing `rankPhotos` + `/api/photos` proxy — reuse `buildPhotoMediaUrl`/`rankPhotos` from `@/lib/ai/photo-selection`), (e) explicit closing instruction: "Output ONLY the single-file React component `export default function GeneratedPage()`. No prose, no markdown fences." AU-market, award-grade.
- `runClaudeCLI(prompt: string, opts?: { model?: string; timeoutMs?: number }): Promise<string>` — `child_process.spawn('claude', ['-p','--model', opts.model ?? 'sonnet','--output-format','text','--disallowed-tools','Bash','Edit','Write','Read','WebFetch','WebSearch'])`, write `prompt` to stdin, collect stdout, reject on non-zero exit / spawn ENOENT (with a clear "is the claude CLI installed + logged in?" message) / timeout (default 300000ms). Return stdout.
- `stripCodeFences(s)` — remove ```tsx fences if present.
- `generateSiteViaClaude(projectId: string): Promise<{ success: boolean; error?: string; code?: string }>` — load project business_data (admin client), `selectKnowledge`, `buildClaudePrompt`, `runClaudeCLI`, strip fences, `validateAndAutoFix` (from `@/lib/ai/validation`), `updateProjectWithCode` (from `@/lib/ai/project-persistence`), set project status 'review' on success / 'error' on failure. Mirror the save/status writes that `generateAndSaveWebsite`'s template path does (read it for exactness).
