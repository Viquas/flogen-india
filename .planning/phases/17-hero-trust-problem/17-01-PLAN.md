**A) Create `hooks/use-scroll-animation.ts`:**

Create a "use client" custom React hook `useScrollAnimation` that uses IntersectionObserver to trigger CSS class-based animations on scroll.

API design:
```typescript
export function useScrollAnimation(options?: { threshold?: number; rootMargin?: string }): React.RefObject<HTMLElement>
```

Implementation:
- Returns a ref to attach to any element (section wrapper, div, etc.)
- When the element enters viewport (threshold 0.15 by default), add a CSS class `animate-in` to it
- The element starts with `opacity: 0; transform: translateY(24px)` (set via initial class `animate-on-scroll`)
- When `animate-in` is added: `opacity: 1; transform: translateY(0); transition: opacity 700ms ease-out, transform 700ms ease-out`
- Use `useEffect` with cleanup (disconnect observer on unmount)
- Observe once — after triggering, unobserve the element (animations should not reverse on scroll up)
- **prefers-reduced-motion**: Check `window.matchMedia('(prefers-reduced-motion: reduce)')`. If matches, skip adding `animate-on-scroll` class entirely (element stays visible, no animation)
- Export a companion CSS string constant `SCROLL_ANIMATION_STYLES` that contains the CSS for `.animate-on-scroll` and `.animate-on-scroll.animate-in` classes. This will be injected into the layout's style tag.

Keep it simple — under 50 lines. No external dependencies.
