  <name>Task 1: Create from-url and from-data API endpoints</name>
  <files>app/api/custom-build/from-url/route.ts, app/api/custom-build/from-data/route.ts</files>
  <action>
Create two POST API route handlers:

**POST /api/custom-build/from-url**
1. Accept `{ url: string }` in request body. Validate url is non-empty.
2. Extract Place ID from the Google Maps URL using these patterns:
   - `maps.google.com/maps/place/...` URLs containing `/data=...!1s` followed by the Place ID (e.g., `!1sChIJ...`)
   - Direct Place ID in path: `/place/ChIJ.../` or `?cid=...`
   - `goo.gl/maps/` short links — follow the redirect by fetching with `redirect: 'follow'` then parse the expanded URL
   - Fallback: if no Place ID extractable, use the full URL path text after `/place/` as a text search query
3. If Place ID found: fetch place details from `https://places.googleapis.com/v1/places/{placeId}` with headers `X-Goog-Api-Key: process.env.GOOGLE_PLACES_API_KEY` and `X-Goog-FieldMask: id,displayName,formattedAddress,nationalPhoneNumber,internationalPhoneNumber,rating,websiteUri,primaryType,primaryTypeDisplayName`. Parse response.
4. If Place ID NOT found but search query available: use Text Search API at `https://places.googleapis.com/v1/places:searchText` (same pattern as lib/discovery.ts) with `pageSize: 1` to find the place. Take the first result.
5. Build business_data object matching the pattern from leads/[id]/generate (placeId, businessName, description, services, contactInfo, industry). Use `primaryTypeDisplayName?.text` or `primaryType` for industry fallback to 'Professional Services'.
6. Insert project into `projects` table with `source: 'custom'`, `status: 'queued'`, `version: 1`.
7. Call `generationQueue.add(project.id)`.
8. Return `{ success: true, projectId: project.id }` (200).
9. On errors: return `{ error: string }` with appropriate status (400 for bad URL, 404 for place not found, 500 for server errors).

**POST /api/custom-build/from-data**
1. Accept `{ data: string }` in request body. Validate data is non-empty.
2. Try `JSON.parse(data)`. If valid JSON:
   - Extract fields: businessName (or name), address, phone, email, website, industry (or category/type), description, services.
   - Build business_data object with extracted fields. Use 'Professional Services' as industry fallback.
3. If JSON.parse fails (freeform text):
   - Pass the raw text as the business description. Set businessName to the first line (trimmed, max 100 chars). Set industry to 'Professional Services'.
   - Build a minimal business_data object.
4. Insert project into `projects` table with `source: 'custom'`, `status: 'queued'`, `version: 1`.
5. Call `generationQueue.add(project.id)`.
6. Return `{ success: true, projectId: project.id }` (200).
7. On errors: return `{ error: string }` with appropriate status.

Both endpoints use `createAdminClient()` from `@/lib/supabase/admin` and `generationQueue` from `@/lib/queue`.
