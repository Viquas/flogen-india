**1. Create `lib/portal/dns-verify.ts`** -- Google DoH verification utility:
- `verifyTxtRecord(domain: string, expectedValue: string): Promise<{ verified: boolean; records: string[] }>`
  - Fetch `https://dns.google/resolve?name=${domain}&type=TXT` with `Accept: application/dns-json` header
  - Parse response, filter Answer array for type 16 (TXT), strip surrounding quotes from data
  - Return verified=true if any record contains the expectedValue
- `generateVerificationToken(claimId: string): string` -- returns `flogen-verify-{first8CharsOfClaimId}` as the TXT value to add

**2. Create `lib/portal/domain-search.ts`** -- Domainr API wrapper:
- `checkDomainAvailability(domain: string): Promise<DomainStatus[]>` where `DomainStatus = { domain: string; zone: string; status: string; summary: 'inactive' | 'active' | 'unknown' }`
  - Fetch `https://domainr.p.rapidapi.com/v2/status?domain=${domain}` with `x-rapidapi-key` and `x-rapidapi-host` headers
  - Return the status array
- `searchDomains(query: string): Promise<{ domain: string; host: string; path: string }[]>`
  - Fetch `https://domainr.p.rapidapi.com/v2/search?query=${query}`
  - Return results array
- Add disclaimer constant: `AVAILABILITY_DISCLAIMER = "Availability may vary. Check directly at the registrar before purchasing."`
- Generate registrar links: `getRegistrarLink(domain: string, registrar: 'godaddy' | 'namecheap' | 'google'): string` returning deep links like `https://www.godaddy.com/domainsearch/find?checkAvail=1&domainToCheck={domain}`

**3. Create `lib/portal/domain-suggest.ts`** -- AI domain suggestion:
- `generateDomainSuggestions(businessName: string, category: string, unavailableDomain: string): Promise<string[]>`
  - Use `generateText` from `ai` with `google('gemini-2.0-flash')` model
  - Prompt: "Generate 20 creative, professional domain name suggestions for a {category} business called '{businessName}'. The domain '{unavailableDomain}' is taken. Suggest alternatives using synonyms, abbreviations, location hints, and creative TLDs (.io, .co, .dev, .shop, .store, etc). Return ONLY a JSON array of domain strings, no explanation."
  - Parse the response as JSON array of strings
  - Return the array (caller handles availability checking)

**4. Create `app/api/portal/domain/subdomain/route.ts`** -- POST handler:
- Auth check (createClient + getUser)
- Accept JSON: `{ slug: string }` (the subdomain part, e.g. "joes-pizza")
- Validate slug: lowercase alphanumeric + hyphens, 3-50 chars, no leading/trailing hyphens
- Get user's claim via admin client
- Update claim: `domain_option = 'subdomain'`, `domain_value = '{slug}.flogen.com'`
- Return `{ success: true, subdomain: '{slug}.flogen.com' }`

**5. Create `app/api/portal/domain/verify/route.ts`** -- POST handler:
- Auth check
- Accept JSON: `{ domain: string }`
- Get user's claim, generate verification token from claim ID
- Call `verifyTxtRecord(domain, token)`
- If verified: update claim `domain_option = 'existing'`, `domain_value = domain`
- Return `{ verified: boolean, records: string[], token: string }`
- Set `maxDuration = 15`

**6. Create `app/api/portal/domain/search/route.ts`** -- GET handler:
- Auth check
- Read `query` from URL search params
- Call `checkDomainAvailability(query)`
- Return `{ results: DomainStatus[] }`
- Set `maxDuration = 15`

**7. Create `app/api/portal/domain/suggest/route.ts`** -- POST handler:
- Auth check
- Accept JSON: `{ businessName: string, category: string, unavailableDomain: string }`
- Call `generateDomainSuggestions(businessName, category, unavailableDomain)`
- Batch-check all suggestions against Domainr (batch the status calls, max 5 concurrent with Promise.allSettled)
- Filter to only available domains (summary === 'inactive')
- If fewer than 3 available: generate another round of 15 suggestions, check those too (per CONTEXT.md decision)
- Return `{ suggestions: { domain: string; available: boolean }[] }` (only available ones)
- Set `maxDuration = 30`

All API routes: `export const dynamic = 'force-dynamic'`, auth check pattern, Zod validation, `[Portal/Domain]` log prefix.
