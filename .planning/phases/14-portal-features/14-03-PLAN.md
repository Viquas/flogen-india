**0. Install sharp:** Run `npm install sharp` before creating files.

**1. Create `lib/portal/png-utils.ts`** -- zero-dependency PNG alpha detection:
- `pngHasAlpha(buffer: Buffer | Uint8Array): boolean`
  - Verify PNG signature at bytes 0-3 (0x89, 0x50, 0x4E, 0x47)
  - Read color type at byte offset 25
  - Return `(colorType & 4) !== 0` (bit 2 indicates alpha)
  - Return false for non-PNG files

**2. Create `lib/portal/logo-bg-removal.ts`** -- Gemini green-screen + sharp:
- `removeLogoBackground(imageBuffer: Buffer, mimeType: string): Promise<{ success: boolean; resultBuffer?: Buffer; error?: string }>`
  - Step 1: Use `sharp` to resize input to max 2000px on longest edge (prevents Gemini timeout on large images). Keep aspect ratio. Only downscale, never upscale.
  - Step 2: Call `generateText` from `ai` with `google('gemini-2.0-flash-exp')` model:
    - Message with image attachment (the resized buffer) and text: "Replace ONLY the background of this logo with solid chromakey green (#00FF00). Keep the logo subject EXACTLY as-is -- do not modify any colors, text, shapes, or details. The entire background must be a single uniform #00FF00 green with NO gradients, shadows, or variation."
    - `providerOptions: { google: { responseModalities: ['TEXT', 'IMAGE'] } }`
  - Step 3: Extract image from `result.files` (find first file with mediaType starting with 'image/')
  - Step 4: Use `sharp` to process the green-screen image:
    - `sharp(greenBuffer).ensureAlpha().raw().toBuffer({ resolveWithObject: true })`
    - Iterate pixels (RGBA, 4 bytes each): if green channel > 180 AND red < 120 AND blue < 120, set alpha to 0
    - Reconstruct PNG: `sharp(processedPixels, { raw: { width, height, channels: 4 } }).png().toBuffer()`
  - Wrap entire flow in try/catch. On any error, return `{ success: false, error: message }`

**3. Create `app/api/portal/logo/upload/route.ts`** -- POST handler:
- Auth check via createClient + getUser
- Accept FormData with `file` (File, required)
- Validate: PNG or JPEG only (magic bytes), max 5MB
- Get user's claim via admin client
- Upload to Supabase Storage: `claim-uploads/{claimId}/logo/{timestamp}-{random}.{ext}`
- Get public URL for the uploaded file
- Detect if PNG has alpha channel using `pngHasAlpha()` -- pass this info in response
- Return `{ url: publicUrl, hasAlpha: boolean, path: storagePath }`
- Set `maxDuration = 30`, `dynamic = 'force-dynamic'`

**4. Create `app/api/portal/logo/remove-bg/route.ts`** -- POST handler:
- Auth check
- Accept JSON: `{ logoUrl: string }` (the URL of the uploaded logo)
- Download the logo from the URL (fetch)
- Call `removeLogoBackground(buffer, mimeType)`
- If success: upload the processed PNG to storage at `{claimId}/logo/processed-{timestamp}.png`, get public URL
- If failure: auto-create a `client_request` of type `agent_call` with content `{ description: "Background removal failed for uploaded logo. Please process manually.", original_logo_url: logoUrl }` -- return `{ success: false, error: "Background removal failed. Our agents will do this manually.", agentRequestCreated: true }`
- On success: return `{ success: true, processedUrl: publicUrl, originalUrl: logoUrl }`
- Set `maxDuration = 60` (Gemini processing can be slow), `dynamic = 'force-dynamic'`
