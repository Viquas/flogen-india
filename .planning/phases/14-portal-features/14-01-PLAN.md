**POST handler** -- create a new change request:
- Auth check same as GET
- Parse multipart FormData (not JSON) to support file uploads
- Extract fields: `description` (string, required, max 2000 chars), `files` (File[], optional, max 3, 5MB each)
- Validate files with magic bytes: allow PNG (0x89504E47), JPG (0xFF D8 FF), WebP (0x52494646), PDF (0x25504446 = %PDF). Reject anything else.
- Get user's claim via admin client: `claims.select('id, project_id').eq('auth_user_id', user.id).order('created_at', { ascending: false }).limit(1).single()`
- Upload each valid file to Supabase Storage bucket `claim-uploads` at path `{claim.id}/requests/{timestamp}-{random}.{ext}`, using admin client
- Get public URLs for uploaded files
- Insert into `client_requests`: `{ claim_id: claim.id, project_id: claim.project_id, auth_user_id: user.id, type: 'text_change', status: 'pending', content: { description, file_urls: [...publicUrls] } }`
- Return `{ request: insertedRow }` with 201 status
- Wrap in try/catch, log errors with `[Portal/Requests]` prefix, return `{ error: string }` on failure
