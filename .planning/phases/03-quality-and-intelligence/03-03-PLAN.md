**2. Create webgen/app/dashboard/analytics/actions.ts** with `"use server"` directive.

Import `createAdminClient` from `@/lib/supabase/admin`.

Implement these server actions:

**a) `getSuccessRatesByDay(days: number = 7, filters?: { model?: string; industry?: string }): Promise<Array<{ date: string; success: number; failure: number; error: number }>>`**

Query `projects` table grouped by date:
- Select projects from the last N days
- Group by `date_trunc('day', created_at)` (use JS date grouping since Supabase JS client doesn't support date_trunc directly -- fetch raw data and aggregate in JS)
- For each day, count projects by status: 'approved' + 'review' = success, 'error' = error, 'generating' + 'queued' = in-progress (exclude from chart)
- If `filters.model` provided, join with `generation_costs` to filter by model
- If `filters.industry` provided, filter by `business_data->>'industry'` using `.filter('business_data->>industry', 'eq', filters.industry)` or equivalent textSearch
- Use `date-fns` `format(date, 'MMM dd')` for display labels
- Default to last 7 days. Cap at 30 days max.

**b) `getTimingStats(days: number = 7, filters?: { model?: string; industry?: string }): Promise<{ p50: number; p95: number; avg: number; dataPoints: Array<{ date: string; avgMs: number }> }>`**

Query `queue_jobs` where both `started_at` and `completed_at` are non-null:
- Compute duration in milliseconds for each job: `completed_at - started_at`
- If filters provided, join with projects table for industry, or use model_id column for model
- Calculate p50: sort durations, take middle value
- Calculate p95: sort durations, take value at 95th percentile index
- Calculate avg: sum / count
- Also return daily averages as dataPoints for charting
- Convert to seconds for display (divide by 1000)

**c) `getCostBreakdown(days: number = 7, filters?: { model?: string; industry?: string }): Promise<{ totalSpend: number; costPerSuccess: number; byModel: Array<{ model: string; totalCost: number; callCount: number }> }>`**

Query `generation_costs` table:
- Sum `estimated_cost_usd` for total spend (within date range)
- Group by `model` for per-model breakdown
- Count successful projects (status = 'review' or 'approved') for costPerSuccess calculation
- Apply model/industry filters as applicable

**d) `getFilterOptions(): Promise<{ models: string[]; industries: string[] }>`**

Query distinct model values from `generation_costs` and distinct industry values from `projects.business_data->>'industry'` (or parse JSONB).
Return sorted arrays for the filter dropdowns.

All functions must handle empty result sets gracefully (return zeros/empty arrays, not null).
