Create a GET endpoint at app/api/leads/batches/route.ts that:

1. Accepts a `date` query param (YYYY-MM-DD format). Defaults to today if missing.
2. Queries `lead_lists` table for all rows where `created_at` is between startOfDay and endOfDay of the given date.
3. Groups results by `batch_id` in application code (Supabase doesn't support GROUP BY with full row data easily).
4. Returns JSON structure:
```json
{
  "batches": [
    {
      "batch_id": "uuid",
      "query": "dentists",        // derived from first lead's industry field
      "location": "Bangalore",    // derived from first lead's location field
      "lead_count": 15,
      "created_at": "2026-03-26T14:32:00Z",  // earliest created_at in batch
      "leads": [
        {
          "id": "uuid",
          "business_name": "...",
          "email": null,
          "phone": "+91...",
          "address": "...",
          "maps_url": "...",
          "raw_data": {...}
        }
      ]
    }
  ]
}
```

Follow the pattern from app/api/discovery/google-places/route.ts:
- Import `NextRequest`, `NextResponse` from `next/server`
- Import `createAdminClient` from `@/lib/supabase/admin`
- Use date-fns `startOfDay`, `endOfDay`, `parseISO` for date range
- Wrap in try/catch, return `{ error: message }` with status 500 on failure
- Order batches by created_at descending (newest first)
- Order leads within each batch by business_name ascending
