**Migration 1: `20260326000001_create_lead_lists.sql`**

Create the `lead_lists` table with these columns:
- `id` UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `batch_id` TEXT NOT NULL — groups leads from a single discovery run (NOT a foreign key to batches table; lead batches are independent)
- `place_id` TEXT — Google Places ID for deduplication (nullable; some leads may lack it)
- `business_name` TEXT NOT NULL
- `phone` TEXT — nullable, Google Places may not return it
- `email` TEXT — nullable, Google Places rarely returns email
- `address` TEXT — nullable
- `website` TEXT — nullable, URL of existing website if any
- `maps_url` TEXT — Google Maps search URL for the business
- `rating` NUMERIC(2,1) — nullable, Google rating (e.g. 4.5)
- `review_count` INTEGER — nullable
- `industry` TEXT — the industry tag from the search
- `location` TEXT — the location from the search query
- `raw_data` JSONB — full Google Places API response for this place
- `created_at` TIMESTAMPTZ NOT NULL DEFAULT now()

Add indexes:
- `idx_lead_lists_batch_id` on `batch_id` (for listing leads by batch)
- `idx_lead_lists_place_id` on `place_id` (for global deduplication checks)
- `idx_lead_lists_created_at` on `created_at DESC` (for date-based listing in Phase 22)

**Migration 2: `20260326000002_add_projects_source.sql`**

ALTER TABLE projects:
- ADD COLUMN `source` TEXT NOT NULL DEFAULT 'discovery' CHECK (source IN ('discovery', 'custom', 'code-drop'))

This is safe for existing rows — they all get default 'discovery'. No backfill needed.
