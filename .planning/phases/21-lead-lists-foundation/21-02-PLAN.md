**File 1: `lib/lead-discovery.ts`**

Create a new module that reuses the Google Places pagination logic from `lib/discovery.ts` but saves results to `lead_lists` instead of creating projects/batches.

Export these types and function:

```typescript
export interface LeadDiscoveryConfig {
  query: string
  location: string
  industry: string
  entries: number
  skipWithWebsite?: boolean  // defaults to true, same as discovery
}

export interface LeadDiscoveryResult {
  batchId: string       // unique batch ID for this lead list run
  savedCount: number    // leads actually saved
  skippedCount: number  // duplicates or filtered out
  totalFetched: number  // raw count from API
}
```

Implement `discoverLeads(config: LeadDiscoveryConfig): Promise<LeadDiscoveryResult>`:

1. Validate `GOOGLE_PLACES_API_KEY` exists (same pattern as `lib/discovery.ts`)
2. Generate a `batchId` using `crypto.randomUUID()` — NOT a foreign key to the batches table, just a grouping string
3. Build the primary query: `${config.query || config.industry} in ${config.location}`
4. Use the same `fetchOnePage()` pattern from discovery.ts — copy the internal function (or extract to shared, but copying is simpler and avoids touching existing code). Use the same URL (`https://places.googleapis.com/v1/places:searchText`), same headers, same FieldMask (but ADD `places.websiteUri` to the FieldMask if not already present — it IS already in discovery.ts via the websiteUri filter)
5. Paginate through results up to `config.entries` (max 100), same page budget (MAX_API_PAGES = 20)
6. For each page of results:
   a. **Global dedup against lead_lists by placeId**: Query `supabase.from('lead_lists').select('place_id').in('place_id', pageIds)` to find already-saved leads. Skip any place whose placeId already exists in lead_lists.
   b. **Skip businesses with websites** if `skipWithWebsite` is true (default): filter out places where `websiteUri` is present
   c. Track `seenPlaceIds` Set to avoid cross-page dupes within this run
7. Build fallback query if primary under-returns (same `buildFallbackQuery` logic from discovery.ts — copy the function)
8. For all valid places, bulk insert into `lead_lists`:
   ```typescript
   const leadsToInsert = validPlaces.map(place => ({
     batch_id: batchId,
     place_id: place.id || null,
     business_name: place.displayName?.text || 'Unknown Business',
     phone: place.internationalPhoneNumber || place.nationalPhoneNumber || null,
     email: null,  // Google Places doesn't return email
     address: place.formattedAddress || null,
     website: place.websiteUri || null,
     maps_url: place.formattedAddress
       ? `https://www.google.com/maps/search/?api=1&query=${encodeURIComponent((place.displayName?.text || '') + ' ' + (place.formattedAddress || ''))}`
       : null,
     rating: place.rating || null,
     review_count: place.userRatingCount || null,
     industry: config.industry || null,
     location: config.location || null,
     raw_data: place,  // full API response for this place
   }))
   ```
9. Insert via `supabase.from('lead_lists').insert(leadsToInsert)`
10. Return `{ batchId, savedCount: leadsToInsert.length, skippedCount, totalFetched }`
11. If zero valid results after all pages, throw descriptive error (same pattern as discovery.ts)

Use `[LeadDiscovery]` as log prefix for all console.log calls.

**File 2: `app/api/leads/discover/route.ts`**

Create POST route handler following the exact pattern of `app/api/discovery/google-places/route.ts`:

1. Parse request body: `{ query, location, industry, entries, skipWithWebsite }`
2. Validate: `query` or `industry` required, `entries` clamped 1-100 (default 20)
3. Call `discoverLeads()` from `@/lib/lead-discovery`
4. Return JSON: `{ success: true, batchId, savedCount, skippedCount, totalFetched }`
5. Error handling: catch and return `{ error: message }` with status 500, or status 400 for validation errors
6. For known non-fatal conditions (no places found), return `{ success: false, message, savedCount: 0 }` with status 200

Import pattern:

