6. **PORTFOLIO** — sectionTitle, sectionSubtitle, items: array of 6 [{name, category, image: string (placeholder path), demoUrl: string}]. Use fictional businesses: a restaurant, barbershop, dental clinic, fitness studio, real estate agent, coffee shop
7. **BENEFITS** — sectionTitle, items: array of 6 [{icon: string, title, description}]. Outcome-focused: "Launch in 48 Hours", "Mobile-First Design", "Built to Convert", "SEO-Ready From Day One", "Dedicated Support", "No Hidden Fees"

**Design Token Strategy:**
Instead of modifying globals.css (which would affect admin/client), apply design tokens directly in the layout via a combination of:
1. Tailwind utility classes on the wrapper
2. A `<style>` tag or CSS custom properties scoped to the marketing wrapper using a `.marketing` class

Apply these CSS custom properties scoped under `.marketing`:

--mkt-bg: #0A0A0A;

**Grain Texture:**
Add a CSS pseudo-element for the subtle grain noise overlay on dark sections. Implement via a `::before` pseudo-element on the wrapper with a small inline SVG noise pattern as a background-image (data URI), fixed position, pointer-events-none, opacity ~0.03-0.05, mix-blend-mode: overlay.

**Layout Structure:**
```tsx

    {children}
  </main>

```

**Scoped styles** — embed a `<style>` tag in the layout (or use Tailwind @apply in a scoped way) for:
- `.marketing` wrapper base styles
